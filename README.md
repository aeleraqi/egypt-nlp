An NLP toolkit specifically designed for processing **Egyptian Arabic** — the most widely spoken Arabic dialect.

## 📖 About

Egyptian Arabic differs significantly from Modern Standard Arabic (MSA) in vocabulary, morphology, and syntax. This library provides reliable NLP tools for Egyptian dialect text that standard Arabic NLP pipelines often fail to handle correctly.

## ✨ Features

- Egyptian Arabic text normalization and preprocessing
- Dialect-aware tokenization
- Stopword removal for Egyptian colloquial Arabic
- Text classification support
- Sentiment analysis utilities

## 🚀 Getting Started

```bash
git clone https://github.com/aeleraqi/egypt-nlp.git
cd egypt-nlp
pip install -r requirements.txt
```
